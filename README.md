# Ponceano Multiservicios

Este repositorio contiene el backend de licencias (`PonceanoLicenciaAPI`), el sitio público y el cliente de escritorio/móvil (`PonceanoFacturador`).

Para configurar, compilar y verificar el cliente, consulta `PonceanoFacturador\README.md` y `PonceanoFacturador\INTEGRACION-LICENCIAS.md`. No agregues claves de firma, contraseñas de publicación, tokens Firebase ni credenciales de servicios.
